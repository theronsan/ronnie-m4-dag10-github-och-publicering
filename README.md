# Kafé Kardemumma

## A responsive website for a fictional café

This is the final part of a practical assignment within the UX/UI and front-end development training program at Lexicon. The task involves publishing the project on GitHub Pages.

The website includes a home page and a contact page featuring a table-booking form. It also has built-in support for Dark Mode.

Technologies used in this project are:

- HTML
- CSS

Live link: [Kafé Kardemumma](https://theronsan.github.io/ronnie-m4-dag10-github-och-publicering/)
